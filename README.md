# Softnexa AI Technologies — React frontend

A responsive single-page company website built with React, TypeScript, Vite, Framer Motion, and Lucide icons.

## Run locally

Requirements: Node.js 20+ recommended.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```

The production output is written to `dist/`.

## Deploy to Cloudflare Pages

1. Push this project to a GitHub repository.
2. Create a Pages project and connect the repository.
3. Build command: `npm run build`
4. Build output directory: `dist`
5. Deploy.

## Important notes before launch

- The contact form validates required fields and opens the visitor's default email application with a prefilled draft. It does not submit to a backend or store data.
- Confirm your company services, pricing, legal business details, and social links before launch.
- Portfolio section is intentionally not populated with fake client projects or fabricated metrics.
- Add a custom favicon and social sharing image when you finalize the logo assets.
- The site uses Google Fonts; for a fully self-hosted setup, download and bundle the fonts locally.
